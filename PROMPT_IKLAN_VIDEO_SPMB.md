## 💡 Tips Penggunaan di Tools AI (Kling / Runway / Luma):

1. **Pilih Mode Image-to-Video**: Di dashboard AI, pilih opsi **"Image to Video"** (bukan Text to Video).
2. **Upload Screenshot**: Masukkan gambar screenshot HP Anda pada slot **First Frame / Image Prompt**.
3. **Paste Prompt**: Masukkan prompt teks per scene di atas pada kolom deskripsi prompt.
4. **Motion Slider (Jika ada)**: Atur kekuatan gerakan (*Motion Strength*) di angka sedang (**3–5 dari 10**) agar tampilan layar website tidak rusak atau berubah bentuk, namun latar belakang dan kameranya bergerak sinematik.
